Subtitles for your whole library, made on your own server.

SubGen scans your media folders, transcribes the audio with Whisper, translates it with local models, and writes SRT, ASS or WebVTT files right beside each video. Your media stays on your hardware.

Everything between the audio track and a finished subtitle file

SubGen 0.4 rebuilds the pipeline around subtitle quality: cues that read well, no wasted transcription, and proper tools for fixing the last few lines by hand.

Runs entirely on your hardware

Transcription and translation happen inside one container, on CPU or an NVIDIA GPU. Nothing is sent to a cloud service, and nothing is billed per minute.

  • faster-whisper transcribes from the media audio, picking CUDA automatically when a GPU is present.
  • Local translation with Hugging Face models stored on your disk, or your own Ollama or LibreTranslate server.
  • No surprise downloads. Models download only when you click install. If a model is missing, the job fails visibly instead of reaching out.

Cues people can actually read

Raw speech recognition output arrives in long, uneven chunks. The subtitle-quality engine rebuilds it from word timestamps into cues that follow the rules you set.

  • Re-segmentation by characters per line, lines per cue, minimum and maximum duration, and the gap between cues.
  • Line balancing splits two-line cues at natural points so neither line is a stub.
  • Hallucination filtering drops the repeated phrases Whisper sometimes invents over silence and music.

Transcribe once, translate many

Transcription is the slow part, so SubGen does it once per file. The transcript is cached and reused for every target language and format, including ones you add months later.

  • One pass of Whisper feeds Arabic, French, Spanish and any other target language.
  • SRT, ASS and WebVTT from the same cues, written atomically so players never see half a file.
  • Sidecars your player finds, named like Movie (2024).ar.srt next to the video.

Scans that know what is already there

Point SubGen at a library and it works out which files actually need subtitles, so a first scan of a large collection does not bury the queue.

  • Skips covered files that already have a matching external subtitle, including variants like Movie.eng.srt, or an embedded subtitle track.
  • Ignore patterns keep samples, trailers and extras out of the queue.
  • Prunes deleted media from the inventory and picks the audio track that matches the language you expect.
  • Waits for copies to finish before touching files that are still being written.

Studio and a real subtitle editor

Not everything lives in a library. Drop a single file into Studio and download its subtitles when the job finishes. Then fix the lines that matter in the editor.

  • Studio takes video or audio by drag and drop. Uploads expire on their own after the retention window you choose.
  • Edit against the picture with a video preview, timing shift, split and merge, and find and replace.
  • Readability warnings flag cues that are too long or too fast to read before you save.

How a job runs

Every subtitle goes through the same stages, and the queue shows which stage each job is in.

  1. Find

    A library scan or a Studio upload adds the file to the queue.

  2. Probe

    ffprobe reads the duration and tracks, and SubGen picks the right audio track.

  3. Extract

    The chosen audio track is decoded for speech recognition.

  4. Transcribe

    faster-whisper with word timestamps, or a cached transcript when one exists.

  5. Shape

    The quality engine builds balanced, readable cues and drops hallucinations.

  6. Translate

    Each target language, with a local model or your own provider.

  7. Write

    An atomic write of SRT, ASS or WebVTT beside the media.

Quick start

You need Linux with Docker Engine and Compose v2. The image targets linux/amd64. For GPU transcription, add an NVIDIA GPU, a current driver and the NVIDIA Container Toolkit.

  1. Clone and prepare folders

    Configuration, models and media live in folders you control.

    shell
    git clone https://github.com/Fahed-Alhammadi/SubGen.git
cd SubGen
cp .env.example .env
mkdir -p data/config data/models media
chown -R 1000:1000 data media

  2. Set your credentials

    Replace the placeholders in .env. Generate a signing key with openssl rand -hex 32.

    .env
    SUBGEN_ADMIN_USERNAME=admin
SUBGEN_ADMIN_PASSWORD=replace-with-a-long-unique-password
SUBGEN_SECRET_KEY=replace-with-at-least-32-random-characters

  3. Start SubGen

    The compose file grants NVIDIA GPU access. On a CPU-only host, comment out gpus: all first and the same image uses the CPU.

    shell
    docker compose up -d

  4. Install a model and add a library

    Open http://127.0.0.1:8080 and sign in. In the Model vault, install a recommended Whisper model, plus a translation model if you want local translation. Then add each mounted folder under Libraries, choose its languages and formats, and select Scan now.

Updating. Back up /config, then run docker compose pull and docker compose up -d. For reproducible deployments, pin a version with SUBGEN_IMAGE=ghcr.io/fahed-alhammadi/subgen:0.4 in .env.

Remote access. Keep the default localhost bind and put SubGen behind an HTTPS reverse proxy. Mount extra libraries as separate paths below /media.

Questions

Does SubGen send my media or audio anywhere?

No. Transcription and the built-in translation provider run inside the container using models on your disk. The only outbound traffic is a model download you start yourself. If you configure Ollama or LibreTranslate, subtitle text goes to the address you enter, which is usually another container on the same machine.

Do I need an NVIDIA GPU?

No. The same image runs on CPU and on NVIDIA GPUs. With the device set to auto, SubGen uses CUDA when it is available. A GPU is much faster for large libraries; smaller Whisper models are practical on CPU.

Which languages are supported?

Whisper transcribes dozens of spoken languages. For local translation, SubGen maps more than 60 common language codes to NLLB, and M2M100 and Marian models cover further pairs. Ollama and LibreTranslate support whatever your chosen model or server supports. Always check timing and translation quality on your own media before enabling unattended processing.

Does it reuse subtitles that already exist?

Existing external and embedded subtitles are used to decide that a file does not need work, so scans skip it. They are never used as a transcription source: SubGen always generates from the audio.

Where are subtitles saved, and will Plex, Jellyfin or Emby find them?

Subtitles are written beside the media with the language code in the name, for example Movie (2024).ar.srt, Movie (2024).en.vtt or Movie (2024).fr.ass. This is the sidecar naming that common media servers look for. Library folders must be writable by the container user.

Can I run it on a NAS with network shares?

Yes, on any Linux host that runs Docker with an amd64 CPU. Local disks, NFS and SMB/CIFS mounts all work. Mount each library at its own path below /media and keep share credentials out of Git.

Is it ready for my irreplaceable library?

SubGen is in active pre-1.0 development. Pin a versioned image, back up /config, and try it on a copy or a small library first. Subtitle writes are atomic and deletions are limited to subtitle files, but backups are still your safety net.
